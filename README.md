# ANSEMTRIX // $TRIX

**THE COMEBACK BROKE THE SIMULATION.**

A cinematic, blue-Matrix memecoin command center for ANSEMTRIX ($TRIX) on Solana.
Built with Next.js (App Router), Tailwind CSS, and Framer Motion.

## ⚡ Quick start

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## 🖼️ Add the hero image (important)

Drop your edited character image (glowing blue eyes / Matrix face) into:

```
public/hero.png
```

The hero section auto-loads `/hero.png`. If it's missing you'll see a placeholder
prompt instead — the rest of the site still works.
